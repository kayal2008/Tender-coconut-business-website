# Tender Coconut Business Website

A responsive business website designed to showcase and promote a tender coconut business through a simple and user-friendly web interface.

## 🌟 Features

- 🥥 Tender coconut product showcase
- 📱 Responsive design for different screen sizes
- 🏪 Business-focused website layout
- 📞 Contact and customer interaction sections
- 🎨 Clean and simple user interface

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**

## 🎯 Project Purpose

This project was created as a web-based business platform for presenting tender coconut products and providing customers with an easy way to explore the business and its offerings.
